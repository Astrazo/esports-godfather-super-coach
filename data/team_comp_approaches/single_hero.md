# Single Hero

## Description
This approach starts with "I want to play this hero" and then builds a composition around them. Exactly how you do this varies depending on the hero you are working around, but it often involves double supports.

## Example Compositions
- Cubey / Reinhardt / Aurelio / Digo / Blocker
- Merisi / Kamaitachi / Dylan / Elemi / Beverly
- Kid / Zealot / Lan / Gang / Lady Deadfire
- Qube / Aurelio / Dylan / Bariel / Charon
- Bart / Hakuna / Enidi / Niels / Palulu
