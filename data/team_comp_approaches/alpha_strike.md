# Alpha Strike

## Description
This composition approaches teamfights by delivering such a massive hammer blow in the first round that everything afterward is cleanup. You will want to stack up the boat as much as possible and optionally apply debuffs to enemy squishies before big fights. The key hero is Chen Fengcheng. Note that Reinhardt's armour shred happens after the boat hits.

## Example Compositions
- Chen Fengcheng / Hakuna / Enidi / Bond / Peiniang Zhu
- Chen Fengcheng / Reinhardt / Lady Deadfire / Shougong Lei / Tiger Boy
